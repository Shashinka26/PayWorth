# PayWorth 💰

A full-stack salary calculation application designed to calculate employee salaries based on different salary calculation modes.

## 🚀 Overview

PayWorth is a full-stack application with a separate backend and frontend. The project provides salary calculation functionality and supports different calculation modes, including hourly salary calculation.

The project was developed to practice full-stack application development, backend API development, frontend integration, and salary calculation logic.

## ✨ Features

- 💰 Salary calculation
- ⏱️ Hourly salary calculation
- 🧮 Salary calculation logic
- 🔗 Backend API integration
- 🖥️ Web-based frontend
- 📦 Separate frontend and backend structure
- 🧪 Backend testing
